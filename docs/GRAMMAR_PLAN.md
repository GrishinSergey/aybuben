# План: граматичний розділ Aybuben

Робочий документ для заповнення граматичного розділу. Призначений для відновлення
контексту між сесіями — читати його **першим**, коли продовжуєш роботу над граматикою.

Гілка: `grammar-section`.

---

## 1. Мета та статус

Заповнити граматичний розділ застосунку темами, які користувач уже вивчав з учителем:
**часи дієслів, дієвідмінювання, відмінки іменників** — плюс суміжні базові теми.
Контент збирається з достовірних джерел (див. §6), обробляється і додається як
TS-модулі у `src/content/`. Без бекенду, без рантайм-LLM.

**Поточний стан:** є одне правило — означений артикль (`ը/ն`).

---

## 2. Рішення (узгоджено з користувачем)

- **Граматичного роду у вірменській немає.** «Зміна дієслів по родах», яку згадав
  користувач, — це насправді **дієвідміна за особами й числами** + поділ дієслів на
  **класи -ел / -ал** (`սիրել` sirel — клас -ел; `հասկանալ` haskanal — клас -ал).
  Обидва аспекти входять у розділ «Дієслово».
- **Обсяг:** названі теми (часи, дієвідміна, відмінки) + суміжні основи
  (неозначений артикль, присвійні артиклі, множина іменників, особові займенники).
  Разом ~12 правил.
- Транслітерація — у стилі Wikipedia (`sirel`, `karmir`), як вимагає `CLAUDE.md`.
- Усе нове додається з `verified: false` (контент від Claude, чекає на перевірку
  носієм/учителем). Бейдж «Не перевірено» вже рендериться.

## 3. Поточний стан кодової бази (станом на старт)

| Файл                            | Роль                                                                         |
|---------------------------------|------------------------------------------------------------------------------|
| `src/content/types.ts`          | Контентні типи. Секція «Граматика» — типи `GrammarRule`, `GrammarTheme` тощо |
| `src/content/themes/grammar.ts` | Тема `grammar` з одним правилом `definite-article`                           |
| `src/content/themes/index.ts`   | Реєстр тем; `findGrammarRule()` шукає правило по slug                        |
| `src/pages/ThemePage.tsx`       | Гілка `kind === 'grammar'` — рендерить картки правил                         |
| `src/pages/GrammarRulePage.tsx` | Сторінка правила; маршрут `/learn/topic/grammar/:ruleSlug`                   |
| `src/App.tsx`                   | Маршрут `GrammarRulePage` уже зареєстровано                                  |
| `src/i18n/translations.ts`      | Ключі `pages.grammar.*`                                                      |

Маршрут правил **захардкоджено** як `/learn/topic/grammar/:ruleSlug`, тож усі правила
мають жити в одній темі зі slug `grammar`. Нові правила = нові елементи `rules[]`.

Тип правила (до змін Фази 0): `intro` → `cases` (картки-пояснення) → `groups`
(приклади-речення за групами) → `sources`. Таблиць-парадигм тип **не підтримує**.

## 5. Правила для створення (12 разом: 1 є + 11 нових)

Порядок у масиві `rules[]` = порядок навчання. Кожне правило: `intro` → 2–4 картки
(`points`) → таблиці (де потрібно) → 3–5 прикладів-речень (`groups`) → джерела.
Емодзі орієнтовні — фіналізувати на етапі контенту.

### A. Артиклі та означники

- [x] **1. Означений артикль** `definite-article` — `ը/ն`. **Готово.**
- [x] **2. Неозначений артикль** `indefinite-article` — `մի` перед іменником;
      коли вживається, коли опускається. **Готово** (`verified: false`).
- [x] **3. Присвійні артиклі** `possessive-articles` — суфікси `-ս` (мій), `-դ` (твій),
      `-ը/ն` (його/її); відмінність від присвійних займенників `իմ/քո`. **Готово**
      (`verified: false`, з таблицею-парадигмою).

### B. Іменник

- [x] **4. Множина** `noun-plural` — `-եր` (односкладові) / `-ներ` (багатоскладові);
      винятки.
- [x] **5. Сім відмінків — огляд** `cases-overview` — таблиця: вірменська назва,
      питання, функція. Зазначити: Ուղղական=Հայցական і Սեռական=Տրական часто збігаються
      формою.
- [x] **6. Відмінювання іменника, тип `-ի`** `noun-declension-i` — повна парадигма
      (одн./мн. × 7 відмінків) у таблиці; коротка згадка інших типів (`-ու`, `-վա`,
      `-ան`, `-ոջ`).

### C. Займенник

- [x] **7. Особові займенники** `personal-pronouns` — `ես/դու/նա/մենք/դուք/նրանք` та їх
      відмінювання (таблиця). Основа для розуміння дієвідміни.

### D. Дієслово

- [x] **8. Дієслово: основи та класи** `verb-basics` — інфінітив, класи **-ел/-ал**
      (`սիրել`/`հասկանալ`), теперішня й аористна основи, допоміжне дієслово `եմ`
      (повна дієвідміна — таблиця).
- [x] **9. Теперішній час** `present-tense` — дієприкметник `-ում` + `եմ/ես/է…`;
      таблиці для обох класів.
- [x] **10. Минулий недоконаний** `past-imperfect` — `-ում` + `էի/էիր/էր…`.
- [x] **11. Аорист (простий минулий)** `aorist` — суфікси `-եց- / -աց-`, особові
      закінчення; синтетична (не аналітична) форма.
- [x] **12. Майбутній час** `future-tense` — форми з `կ-` (`կսիրեմ`) та з `-ու`
      (`սիրելու եմ`); різниця у вживанні.

## 7. Довідка: факти мови (звірити на етапі контенту)

**Сім відмінків (відмінкова система):**

| Вірменська | Українська           | Питання / функція               |
|------------|----------------------|---------------------------------|
| Ուղղական   | Називний             | хто? що? — підмет               |
| Սեռական    | Родовий              | кого? чого? — належність        |
| Տրական     | Давальний            | кому? чому? — непрямий додаток  |
| Հայցական   | Знахідний            | кого? що? — прямий додаток      |
| Բացառական  | Відкладний (аблатив) | від кого/чого? — джерело        |
| Գործիական  | Орудний              | ким/чим? — засіб                |
| Ներգոյական | Місцевий             | у кому/чому? де? — розташування |

Ուղղական і Հայցական часто збігаються формою; Սеռական і Տրական — теж.
Типи відмінювання визначаються закінченням давального: `-ի` (основний, продуктивний),
`-ու`, `-վա`, `-ան`, `-ոջ`, `-ա`, `-ո`.

**Дієслово:** прості часи — теперішній, аорист, майбутній; складені будуються
дієприкметником + допоміжне `եմ`. Теперішній маркер `-ум`, аорист синтетичний
(`-եց-/-աց-`). Іменники й дієслова **не мають роду**.

## 9. Конвенції (з CLAUDE.md)

- Робота на feature-гілці; перед PR — `npm run lint` і `npm run build` чисто.
- Кольори лише через токени палітри, без сирих hex у JSX.
- `font-hy` для вірменського тексту, `font-display` для заголовків.
- Не вгадувати вірменську: якщо форма непевна — `verified: false`.
- **Перевірка скриптів:** вірменські слова в uk/ru-прозі схильні підхоплювати
  кириличні гомогліфи. Після написання контенту прогнати скан мішаних скриптів,
  звірку uk/ru-парадигм і пошук не-вірменських суфіксів (див. історію Фази 2б).
- Комміти короткі, в наказовому способі: `add present tense rule`.
- PR-опис: що додано / що змінено / що перевірити вручну.
